# Source Serif 4

The Numerals demo uses the unmodified Source Serif 4 Regular 4.005 font to
demonstrate proportional/tabular figures, small capitals and oldstyle figures
with the same font on every graphical platform.

- Source: https://github.com/adobe-fonts/source-serif/tree/80d3f8894c09c937bebfa9011247d2e1c79fd6f4
- File: `TTF/SourceSerif4-Regular.ttf`
- SHA-256: `e5a4ee6a3d87bb9024796be390c6771e2a0eb1883dae25effaf57ca01668e24b`
